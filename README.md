# NEP-Cu-Cu2O-thermal-conductivity
The NEP is used for describing the heat transfer across the Cu/Cu2O/Cu in molecular dynamics simulations.
Due to the large size of the complete dataset and simulation files, only selected files are provided in this repository. For more detailed simulation procedures, additional data, or assistance with reproducing the results, please contact the first author, Yang Xi, at xiyang@whu.edu.cn.
